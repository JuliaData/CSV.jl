# Security policy

## Supported versions

Security fixes target the latest registered CSV.jl release. Maintainers can
backport a fix when affected users cannot upgrade safely.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability. Open the repository's
[Security page](https://github.com/JuliaData/CSV.jl/security/advisories) and
select **Report a vulnerability**. GitHub sends the report privately to the
repository maintainers.

Include the affected CSV.jl and Julia versions, impact, smallest safe
reproduction, and any known mitigation. Do not include private data from a CSV
source. The maintainers will coordinate investigation, fixes, and disclosure in
the private advisory.
